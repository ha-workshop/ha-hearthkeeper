# Hearthkeeper

Голосовой ассистент в Telegram для Home Assistant — локальные STT/TTS,
календарь, почта и состояние дома, с тем conversation-агентом, который у вас
уже настроен.

Своего Telegram-клиента у Hearthkeeper нет. Соединение и allowlist чатов держит
ядро `telegram_bot`: Hearthkeeper слушает его события на шине, общается с
агентом `conversation` и отвечает через сервисы `telegram_bot`.

## Статус

| Этап | Объём | Состояние |
|---|---|---|
| M0 | config flow, транспорт, текстовые ответы, `/help`, `/new`, `/voice` | ✅ |
| M1 | голос на вход: OGG → PCM → STT | ⏳ |
| M2 | голос на выход, группы, дедуп после рестарта | ⏳ |
| M3 | скиллы: календарь, почта, дом, брифинг, задачи | ⏳ |
| M4 | `/model`, кнопки, diagnostics, упаковка | ⏳ |

## Требования

- Home Assistant 2026.11 или новее
- Запись `telegram_bot` в режиме polling хотя бы с одним разрешённым чатом
- Агент `conversation`; без него Hearthkeeper просто повторяет сообщения

## Установка

1. HACS → ⋮ → Custom repositories → добавьте
   `https://github.com/ha-workshop/ha-hearthkeeper` как **Integration**.
2. Установите **Hearthkeeper**, перезапустите Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → **Hearthkeeper**.
4. Выберите бота Telegram, затем откройте **Настроить** и укажите агента,
   язык и режим ответа.

## Команды

| Команда | Действие |
|---|---|
| `/help` | Список команд |
| `/new` | Начать новый разговор |
| `/voice on` | Голосовые ответы (появятся в M2) |
| `/voice off` | Текстовые ответы |
| `/voice both` | Текст и голос |
| `/shop` | Список покупок из сущности `todo` (тап — вычеркнуть) |
| `/brief` | Сводка дня (M3) |
| `/model` | Смена агента (M3) |

## Сервисы

```yaml
action: hearthkeeper.say
data:
  chat_id: 123456789
  text: "Дверь гаража всё ещё открыта"
```

- `hearthkeeper.say` — отправить текст в чат
- `hearthkeeper.reset` — забыть контекст разговора (чат или все)
- `hearthkeeper.brief` — отправить брифинг сейчас (M3)

## Приватность

- Хранятся только служебные данные: id чата, conversation id, агент, режим
  ответа, язык, метки времени. Тексты сообщений и содержимое почты/календаря
  на диск не попадают.
- Наружу не уходит ничего, кроме самого Telegram. Облачный агент — только
  если вы сами его выбрали.
- Исходное аудио и содержимое почты пишутся в лог не выше `DEBUG` и без
  содержимого.
