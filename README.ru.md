# Hearthkeeper — голосовой ассистент для Home Assistant

[English](README.md) · **Русский**

Голосовой ассистент в Telegram для Home Assistant — локальные STT/TTS,
календарь, почта и состояние дома, с тем conversation-агентом, который у вас
уже настроен.

Своего Telegram-клиента у Hearthkeeper нет. Соединение и allowlist чатов держит
ядро `telegram_bot`: Hearthkeeper слушает его события на шине, общается с
агентом `conversation` и отвечает через сервисы `telegram_bot`.

## Статус

| Этап | Объём | Состояние |
|---|---|---|
| M0 | config flow, транспорт, текстовые ответы, `/help`, `/new`, `/voice` | ✅ |
| M1 | голос на вход: OGG из Telegram → WAV → пайплайн Assist | ✅ |
| M2 | голос на выход, группы, дедуп после рестарта | ✅ |
| M3 | брифинг: календарь, погода, почта, покупки и состояние дома | ✅ |
| M4 | `/model`, кнопки, diagnostics, упаковка | ✅ |
| M5 | Mini App: личные настройки, сводка и тихие часы | ✅ |

## Требования

- Home Assistant 2026.11 или новее
- Запись `telegram_bot` в режиме polling хотя бы с одним разрешённым чатом
- Агент `conversation`; без него Hearthkeeper просто повторяет сообщения

## Установка

1. Откройте репозиторий в HACS:

   [![Открыть в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ha-workshop&repository=ha-hearthkeeper&category=integration)

   Или вручную: HACS → ⋮ → **Пользовательские репозитории** →
   `https://github.com/ha-workshop/ha-hearthkeeper`, тип **Integration**.
2. Скачайте **Hearthkeeper**, перезапустите Home Assistant.
3. Добавьте интеграцию:

   [![Добавить интеграцию](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=hearthkeeper)

   (*Настройки → Устройства и службы → Добавить интеграцию → Hearthkeeper*.)
4. Выберите бота Telegram, затем откройте **Настроить** и укажите пайплайн
   Assist (агент, STT, TTS и голос берутся из него) и режим ответа.

## Команды

| Команда | Действие |
|---|---|
| `/help` | Список команд |
| `/new` | Начать новый разговор |
| `/voice on` | Голосовые ответы (нужен пайплайн с TTS) |
| `/voice off` | Текстовые ответы |
| `/voice both` | Текст и голос |
| `/shop` | Список покупок из сущности `todo` (тап — вычеркнуть, `/shop del` сначала спросит) |
| `/brief` | Сводка дня: погода, календарь, дом, покупки, почта |
| `/mail` | Почта: счётчики непрочитанных, отправители и темы |
| `/remind 20m текст` | Напоминание через 20 минут; ещё `/remind 20:30 текст`, `/remind list`, `/remind cancel` |
| `/model` | Смена агента для этого чата (кнопки или `/model <имя>`) |
| `/web` | Открыть Mini App: настройки и быстрые действия (личный чат, нужен HTTPS-адрес Home Assistant) |

## Навыки

До того как текст уйдёт conversation-агенту, Hearthkeeper сам распознаёт
несколько коротких фраз. Это работает и с локальным агентом, который ничего не
знает о Home Assistant:

| Фраза | Ответ |
|---|---|
| «сводка», «брифинг» | Та же сводка, что и `/brief` |
| «что у меня сегодня», «планы на завтра» | Календарь на нужный день |
| «что дома», «статус дома» | Свет, открытые двери и окна, климат |

Эти же фразы зарегистрированы как интенты Assist и записаны в
`custom_sentences/`, поэтому их понимает и стандартный агент Assist. Всё
остальное, как и раньше, уходит conversation-агенту.

## Сводка дня

Откройте **Настроить** и выберите источники, которые уже есть в Home Assistant:

- **Календари** — любое число сущностей `calendar.*` (сегодня и завтра);
- **Сущность погоды** — `weather.*`;
- **Список покупок** — тот же `todo.*`, что и у `/shop`;
- **Сенсоры почты** — `sensor.*` от интеграции IMAP со счётчиком непрочитанных.
  Отправители и темы последних писем берутся из событий `imap_content` и
  хранятся только в памяти. Включите **AI-сводку почты**, чтобы попросить
  выбранную AI Task собрать дайджест на 3–5 строк; по умолчанию выключено;
- **Состояние дома** — включённый свет, открытые двери и окна, активный климат.

Укажите **Время сводки** (по умолчанию 08:00) и включите **Утреннюю сводку**.
Ежедневное сообщение приходит в каждый личный чат, где бот уже переписывался.
`/brief` и `hearthkeeper.brief` собирают ту же сводку по запросу; пустой или
сломанный источник убирает только свой раздел.

Естественные фразы тоже работают: «напомни через 20 минут …» и «remind me
in 20 minutes to …». Напоминания живут в памяти и дополнительно создают
постоянное уведомление, поэтому перезапуск Home Assistant очищает очередь.

## Mini App

`/web` присылает кнопку, которая открывает Hearthkeeper прямо в Telegram. Это
панель настроек, а не второй чат:

- **Главная** — агент, режим ответа, новый разговор и активные напоминания;
- **Навыки** — фразы, на которые Hearthkeeper отвечает без агента;
- **Дом** — источники и расписание сводки;
- **Настройки** — личное время и источники сводки, тихие часы, язык и аккаунт
  бота. Быстрые действия (`/brief`, `/shop`, `/mail`, `/remind`) отправляют
  команду в чат, а ответ приходит обычным сообщением.

Личные настройки принадлежат тому аккаунту Telegram, который открыл
приложение, и хранятся вместе с его личным чатом. Настройки интеграции
остаются общими для дома и меняются только в Home Assistant. Календари и
почтовые ящики можно выбирать только из тех, что администратор уже включил.

Страница отдаётся по `/api/hearthkeeper/webapp` и не содержит данных Home
Assistant. В каждом запросе есть Telegram `initData`: подпись проверяется
токеном бота, пользователь должен быть в разрешённых чатах, а изменить можно
только свой личный чат.

Telegram открывает Mini Apps только по HTTPS. Hearthkeeper автоматически
берёт внешний адрес или адрес Home Assistant Cloud. Если ни один из них не
доступен клиентам Telegram, укажите **Адрес Mini App** в **Настроить** —
публичный HTTPS-адрес (существующий туннель или reverse proxy); путь страницы
добавится сам.

## Сервисы

```yaml
action: hearthkeeper.say
data:
  chat_id: 123456789
  text: "Дверь гаража всё ещё открыта"
```

Добавьте `mode: voice` (или `both`), чтобы озвучить сообщение голосом
пайплайна; без него используется режим ответа самого чата.

- `hearthkeeper.say` — отправить текст в чат
- `hearthkeeper.reset` — забыть контекст разговора (чат или все)
- `hearthkeeper.brief` — отправить сводку сейчас в один чат или во все известные личные чаты

## Приватность

- Хранятся только служебные данные: id чата, conversation id, агент, режим
  ответа, язык, метки времени и личные настройки сводки/тихих часов из Mini
  App. Тексты сообщений, напоминания и содержимое почты/календаря на диск не
  попадают; напоминания живут только в памяти.
- Наружу не уходит ничего, кроме самого Telegram. Облачный агент — только
  если вы сами его выбрали, а сводка почты — отдельный opt-in
  (**AI-сводка почты**).
- Исходное аудио и содержимое почты пишутся в лог не выше `DEBUG` и без
  содержимого.

## Диагностика

**Настройки → Устройства и службы → Hearthkeeper → ⋮ → Скачать диагностику**
отдаёт счётчики, id сущностей и настройки — без текстов сообщений, id чатов,
аудио, почты и календаря. Это самый быстрый способ приложить контекст к
сообщению об ошибке.
